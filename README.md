# 坦克大战 · Battle City

一个用原生 HTML5 Canvas 实现的经典坦克大战游戏，无需任何依赖，双击 `index.html` 即可游玩。

## 🎮 玩法

- **移动**：方向键 `↑ ↓ ← →` 或 `W A S D`
- **开火**：空格键或 `J`
- **暂停**：`P` 或 `Esc`
- **开始 / 重新开始**：`Enter`（手机端可直接点击屏幕）
- 手机触屏设备会自动显示虚拟按键

## 🧱 游戏元素

| 元素 | 说明 |
|------|------|
| 🟫 砖墙 | 可被子弹摧毁 |
| ⬜ 钢墙 | 不可摧毁 |
| 🟦 水域 | 坦克无法通过，子弹可越过 |
| 🌳 树林 | 可通行，坦克躲进树林会被遮挡 |
| 🦅 基地 | 保护好它！被击中则游戏结束 |

## ✨ 特性

- 多种敌方坦克（基础 / 快速 / 连发 / 装甲）
- 难度随关卡递增，无限关卡
- 分数、生命、关卡数统计
- 粒子爆炸特效与音效（Web Audio）
- 支持键盘 + 触屏操作

## 🚀 在线游玩

可通过 GitHub Pages 部署，或直接打开 `index.html` 在本地游玩。
